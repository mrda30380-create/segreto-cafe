SEGRETO BACKEND

التشغيل:
1) ثبّت Node.js 18+.
2) افتح Terminal داخل المجلد.
3) نفّذ: npm install
4) انسخ .env.example إلى .env وعدّل ADMIN_PASSWORD.
5) نفّذ: npm start
6) افتح: http://localhost:3000

ما تم:
- Backend بـ Express.
- قاعدة بيانات SQLite.
- الحجز والتعارض يتم فحصهما على السيرفر داخل Transaction.
- حجز مؤقت 10 دقائق قبل الدفع.
- لا يتم تسجيل paid=true من المتصفح.
- حماية Helmet + rate limiting.
- كلمة مرور لوحة الإدارة من ENV فقط.
- API للطاولات والحجوزات ولوحة الإدارة.

الدفع:
تم ترك بوابة الدفع بدون ربط كما طلبت.
ضع رابط بوابة الدفع في PAYMENT_CHECKOUT_URL بعد اختيار مزود الدفع.
لكن تأكيد الدفع النهائي يجب أن يكون Webhook من مزود الدفع إلى السيرفر، وليس بمجرد رجوع المستخدم من صفحة الدفع.


### لوحة الكافيه
بعد تشغيل السيرفر افتح:
`http://localhost:3000/admin.html`

اللوحة محمية بتسجيل دخول من السيرفر. كلمة مرور الإدارة موجودة في `.env` فقط، وليست داخل `index.html` أو `admin.html`. بعد تسجيل الدخول يستخدم الموقع جلسة HttpOnly مؤقتة، ويتم تسجيل الخروج بإلغاء الجلسة.


### حالة الحجز والدفع
- `paid` = **حجز مؤكد ومدفوع** ويظهر بهذه الحالة في لوحة الكافيه.
- `held` = **غير مؤكد - في انتظار الدفع** ولا يُعتبر حجزاً مؤكداً.
- لا يتم اعتبار العميل مؤكداً بمجرد الضغط على زر الحجز؛ تأكيد الدفع الحقيقي يحتاج ربط بوابة الدفع/Webhook.
